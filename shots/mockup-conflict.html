交互要点：气泡在 header 下方、操作条上方，占布局空间；右侧 ▾ 展开/收起冲突文件列表。 列表完全复用工作区改动的文件树（字母 + 路径 + 右侧统计），只是右侧从 +N -N 换成冲突处数。 点文件复用现有底部详情面板，显示带 <<<<<<< 标记的全文； 用户在外部编辑器改完保存后，下次刷新检测到没有冲突标记，就在原处显示 （解决）（绿色），同时把文件教给 git 标记为已解决。 「继续合并」只有剩余冲突全部解决才可点；「中止」随时可用，会二次确认。
